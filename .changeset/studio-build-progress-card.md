An empty workspace whose conversation holds a turn shows that turn in place of the request input: the request, the step the agent is on, the files it has written so far (each opening in the editor), Stop and Show conversation while it runs; once it ends without a module, why — a question, a spent step budget, a stop, a failure with Retry, or a plain reply — and Continue in the conversation. The input returns only when the conversation is empty again. The first module to appear in an empty workspace opens when no tab is open, an Application before a Library.
