## 0.16.0 - 2026-08-11
### Added
* Assert.Equals compares a CEL integer against an integer literal. A CEL int is int64 — a BigInt — while an expected: literal comes out of YAML as a plain number, and YAML has no way to write the other, so every integer-valued expression was unassertable without first casting it to a float. Equality is exact in both directions: the literal must be integral and round-trip to the same int64, so 3 matches 3 but neither 3.5 nor a magnitude a double cannot represent.
