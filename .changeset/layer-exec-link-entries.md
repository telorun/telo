A module artifact layer can now carry executable files and symbolic links. Publish reads each file's kind from the module directory: a symbolic link selected by `files:` or named by the manifest ships as a link (never followed), and a file with any execute bit ships as executable, framed with mode `0o755`. A layer's `integrity` covers both — an executable's line is `<path>\0<digest>\0x` and a link's `<path>\0l\0<target>` — while a regular file's line is unchanged, so every published layer of regular files keeps its `blob` and `integrity`. Materialization restores the execute bit and creates the link. A link must resolve, within the module directory, to a file of its own layer (through other links if need be), and no entry path may repeat or run through another entry of its layer. Publish refuses a link that escapes, points at a directory, names a file in another layer or dangles, and extraction checks every entry before writing any, refusing such a layer with `ERR_MODULE_LAYER_INVALID`, each naming the entry's module-relative path and the reason; extraction also refuses to write beneath a directory that is not a real directory inside the module's cache directory. A symbolic link to a directory matched by `files:`, previously skipped, now fails publish. `include:` resolution still skips symbolic links.
