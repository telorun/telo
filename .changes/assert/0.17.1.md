## 0.17.1 - 2026-08-15
### Fixed
* Assert.Events compared payload leaves with `!==`, so a CEL integer — an int64, i.e. a BigInt — never matched the plain number an `expected:` literal comes out of YAML as. The two rendered identically in the failure report while comparing unequal, making any integer-valued expression in an event payload unassertable. Leaves go through the same comparison Assert.Equals uses.
