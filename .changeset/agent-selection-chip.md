A selection in the source view or the detail panel's YAML pane now goes with the next message to the agent: the composer shows it as a chip naming the file and lines, which opens the file there and can be removed, and the message carries it as a `telo-selection` block. The user's bubble and the queued preview show the same chip, and Edit & resend keeps the selection. The "Send selection to chat" action is removed.
