`telo check` judges what an expression's value is known to be, not only its CEL type's base: a list's element type against the slot's `items`, a map's value type against its members, and — read off the expression itself — a list literal's elements, a map literal's keys and values, a module call's declared result, the elements both sides of a list `+` contribute, and either branch of `?:`. A literal tool message without `toolCallId` concatenated onto a function's message history is now `CEL_TYPE_ERROR` at the argument rather than `ERR_INPUT_INVALID` at run, and a conflict lying wholly beneath a value type's type argument is `CEL_TYPE_ARGUMENT_MISMATCH`. Union slots are read with their shared keywords applied to every branch. The schema comparison now also refuses a value whose listed values (`const` / `enum`) a slot allows none of, and a member the value always carries where the slot declares it `false`; a required member whose own schema declares a `default` is read as filled where an expression fills a resource's field or a call's argument, as the runtime fills defaults there before validating — never in a comparison against an ancestor's contract, which nothing fills.
