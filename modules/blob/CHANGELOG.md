# Changelog

## 0.2.0 - 2026-10-10
### Added
* New module. Blob is storage-neutral object storage: the abstract Blob.Store, the key shape Blob.Key (slash-separated segments, each starting with a letter or digit and continuing with letters, digits, dot, underscore or hyphen; 1 to 512 characters; case-sensitive) and four invocables that name a store through a required store reference. Blob.Put stores bytes or a byte stream with a required contentType (lower-case type/subtype, no parameters, at most 127 characters on each side) and an optional maxBytes, replaces atomically and returns key, size, sha256 and contentType; content over the bound is ERR_BLOB_TOO_LARGE with nothing stored and the previous blob still readable, and a stream chunk that is not bytes is ERR_INPUT_INVALID. Blob.Get returns the content as a byte stream with size and contentType, ERR_BLOB_NOT_FOUND for a missing key and ERR_BLOB_TOO_LARGE before any content is read for a blob over its maxBytes. Blob.Head returns size and contentType. Blob.Delete succeeds for a missing key. Blob.Get and Blob.Head answer the media type in the same lower-case form whatever the store recorded. A store is recognised by its four methods (put, get, head, delete) and only stores: the operations count, hash, bound and raise every code, and each method is handed the invocation context. The contract is docs/store-contract.md and its types are reachable as @telorun/blob. There is no listing, copy, range read or time-limited link.
