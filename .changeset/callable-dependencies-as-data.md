A native function holds its dependencies as data. A `Telo.Callable` kind with its own controller may name any kind but a need type at a `use: dependency` slot (`CALLABLE_DEFINITION_INVALID` no longer refuses it), and at `create()` its controller receives there the referent's configuration as the referent's own controller received it — compile-time expressions evaluated, accessor fields as their bindings, texts as records, every reference inside replaced the same way — without `kind` and `metadata`, deep-cloned and frozen, one copy per referenced resource, never an instance. The reference stays a dependency of the function, so creation order, deferral, reconcile and the rebinding of its callers follow it. A slot is a data slot only when every use it can take is `dependency`; a native function calling a function it holds declares that slot `use: call` — a breaking change for one that held a function at `use: dependency` and called it. `telo check` refuses a referent whose configuration is not data with the new `CALLABLE_REFERENCE_NOT_DATA` at the function's slot — an expression evaluated after creation (a runtime-eval field, a CEL region, a step or function body), a scope, a need, or a reference cycle — and judges a library's resource input at each import supplying it; the kernel refuses the same at creation (`ERR_CALLABLE_REFERENCE_NOT_DATA`). A native function in a template body receives what the body reaches: a sibling entry as the template created it, or an instance through the defining module's imports; a resource of the defining module is refused at the definition and at creation (the body's lookup does not reach it — declare it in `resources:` or hand it in through a bare `self.<field>`), and what a consumer forwards is judged at the consumer's own path. A function kind with a body inheriting such a slot is refused at it, and a deterministic claim is no longer judged against what a data slot holds. The analyzer exports the reader both halves use: `isDataSlot`, `isDataSite`, `isNativeCallableKind`, `callableReferenceNotDataMessage`.
