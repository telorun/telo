# Changelog

## 0.2.0 - 2026-09-25
### Added
* Web page handling. Parse HTML text or bytes (charset sniffed from a byte order mark, a declared charset or a meta tag) into a plain-data page tree CEL can read, with the base URL a page links resolve against; tag and attribute names follow the start-tag alphabet and the parser's own case (lowercase HTML and MathML names, SVG uppercase only in the spec's adjusted names, no svg, math or image element outside its namespace), so a node cannot smuggle markup through a name. Select elements with CSS selectors checked by telo check and matched per Selectors Level 4, including :nth-child(An+B of S), complex selectors inside :is(), :where(), :not() and :has(), the column combinator, and form, language and direction pseudo-classes answered from the markup; pseudo-classes that need a live browser (:hover, :focus, :visited, :target and the like) match nothing. Extract typed fields (text, markup, attributes, numbers and integers, repeated and nested records) whose result is typed from the declaration, failing with ERR_HTML_FIELD_MISSING or ERR_HTML_FIELD_CONVERSION (an attribute is read from the element's own attributes only); a field selector or attribute name may be computed with !cel at any depth. Sanitize untrusted markup against an allowlist of elements, attributes and URL schemes, with the stripAll, basicFormatting and richContent presets; a policy that keeps a raw-text element such as script or style, keeps svg, math or image, lists javascript or vbscript in protocols, allows or forces an on* event handler, or names an element in attributes or setAttributes that elements does not list is refused by telo check at the offending entry (HTML_SANITIZE_RAW_TEXT_ELEMENT, HTML_SANITIZE_NOT_AN_HTML_ELEMENT, HTML_SANITIZE_SCRIPT_PROTOCOL, HTML_SANITIZE_EVENT_HANDLER, HTML_SANITIZE_EVENT_HANDLER_FORCED, HTML_SANITIZE_UNKNOWN_ELEMENT, HTML_SANITIZE_UNKNOWN_ELEMENT_FORCED) and by the controller at creation (ERR_HTML_SANITIZE_POLICY_INVALID), a comment that would end early is dropped, and output whose markup would read back differently is replaced by what it reads back as, so it always serializes (ERR_HTML_NOT_SERIALIZABLE if it does not settle); idPrefix prefixes kept id and name values, id-reference attributes and #fragment links whose target is kept. Serialize back to HTML, checked by parsing the output again: a tree that would not read back as itself (a comment or raw text that would end early, an element inside title or textarea, a child of a void element, a node in a namespace the parser would not give it there, a nested-form mutation) is refused with ERR_HTML_NOT_SERIALIZABLE naming the first differing node. Render plain text or Markdown with GitHub-flavored tables and task lists, read a page title, meta tags, links and JSON-LD, and isolate an article main content (ERR_HTML_NO_MAIN_CONTENT when there is none). Html.escape and Html.unescape are CEL functions.
