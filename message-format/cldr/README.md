# CLDR data

This is CLDR 48.2 for every locale, generated by `message-format/nodejs/scripts/generate-cldr-data.mjs` from the exact-pinned `cldr-core@48.2.0` and `cldr-numbers-full@48.2.0`. Every value is CLDR's, verbatim, and each file records `cldrVersion`. Never edit these files by hand. Run `pnpm -C message-format/nodejs run generate:cldr`; the package's tests fail when a file differs from what the pinned release generates.

| File | Holds |
| --- | --- |
| `plurals.json` | Each locale's cardinal rule strings, samples included, keyed by category. |
| `numbers.json` | Each locale's default-numbering `digits`, `decimal`, `group` and `minusSign` symbols, its standard decimal `pattern` and `minimumGroupingDigits`. An entry equal to what its parent resolves to is omitted. |
| `parent-locales.json` | `main` (the parents number data inherits through), `plurals` (the plurals component's own parents) and `likelyScripts` (each language's likely script, which the `nonlikelyScript` rule reads). |

The root locale is named `root` in every file. The data is used under the Unicode License V3 (`LICENSE`), which every copy of the core carries.
