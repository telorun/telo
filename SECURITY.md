# Security policy

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting: on this repository, open **Security**, then **Report a vulnerability**. Please do not open a public issue or pull request for it.

Include what is affected (a package, module or image and its version), how to reproduce the problem, and the impact you see.

## Supported versions

Only the newest release line receives fixes; it is the only line that publishes (see `RELEASING.md`). Upgrade to it to get a fix.

## What to expect

- An acknowledgement of your report, normally within a few working days.
- A confirmation or a reasoned decline after triage, and updates while a fix is prepared.
- A fix released on the supported line, with the advisory published and you credited unless you ask otherwise.
