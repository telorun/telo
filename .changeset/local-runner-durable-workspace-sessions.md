`telo runner` serves the durable workspace session (breaking). A session is a directory under the state root, `sessions/<sessionId>/` with `workspace/` (the application's files, its seeded `telo-workspace.yaml` and its `.telo` module cache) and `agent/`, all `0700`, kept by id across suspends and runner restarts; the session store is `sessions.sqlite` in the same state root. The state root is `--state-dir`, then `RUNNER_STATE_DIR` (which now names the whole state directory rather than the store's alone), then the per-user application-state directory — `$XDG_STATE_HOME/telo/runner` (`~/.local/state/telo/runner` when unset) on Linux, `~/Library/Application Support/telo/runner` on macOS, `%LOCALAPPDATA%\telo\state\runner` on Windows — instead of the system temp directory, so sessions survive a reboot; with none resolvable or writable (no `HOME`) the runner refuses to start (exit 2), naming `--state-dir` and `RUNNER_STATE_DIR`. The `-o json` result's `stateDir` is the root in use. Nothing runs until Run: each Run spawns the argv the runner core builds (`telo run --watch --no-input --inspect … --no-open <entry>`) of the running executable, or of the release an application names, in the session workspace as its own process group, with the run's env over the runner's own; Stop sends SIGTERM to the group and SIGKILL after the grace, and the run's exit code or signal is reported as the app's ending. Suspend ends the runs and keeps the directory; deleting the session or retention removes it. At boot every stored session that was running is suspended — a local run never outlives the runner — and the sweep removes only the session directories the store does not know, replacing the per-PID directories and their sweep. The runner offers no co-resident agent, so `features.agents` is absent. `--watch-sessions` and `features.watch` are removed, with one-shot run sessions and the bundle upload; the command's `-o json` result no longer carries `watch`.

The desktop app now starts its local runner with a state root under the app's local data directory (`runner/`) instead of the system temp directory, so a workspace's local session, its files and its module cache survive an editor restart.
