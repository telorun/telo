Studio: a browser-stored workspace can be copied into a Telo Cloud project. "Copy to Telo Cloud project…" in the workspace menu writes its files into the project's working copy as uncommitted changes and opens the project; committing puts them in git, after which Studio offers to remove the browser workspace. The target must have no uncommitted changes, files the project already holds are listed before they are replaced, and a copy the repository's limits would refuse is not started.

The view strip above a module and the run dock's header wrap in a narrow pane, so the run controls and the dock's actions stay on screen.
