The agent panel is more compact. The composer is one card with its actions in a row beneath the text and the turn's status beside them. Every tool call, failed, running or done, is a single row: the name, its arguments on one truncated line and the verdict last, with an exit code only when it is not 0. Its details are a preview of a few lines, and "View full output" opens everything in a dialog with Copy.
