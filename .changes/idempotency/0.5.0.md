## 0.5.0 - 2026-07-31
### Added
* `Once` relies on its declared `inputType` to reject a missing or empty `key` instead of re-checking it in the controller. The schema already said so (`required: [key]`, `minLength: 1`) and the kernel now enforces it on every call, so the failure is the ambient `ERR_INPUT_INVALID` — which names the target and the offending value — rather than `ERR_INVALID_KEY`, now removed from the declared union as unreachable.
