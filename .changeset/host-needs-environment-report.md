Needs reaching the root are read from the environment, and `telo needs report` lists them. A `Telo.Application` declares `needs:` as a library does, plus `env: { <field>: <NAME> }` choosing the variable a field is read from. Every need reaching the root unsupplied — the application's own included — is read at load, before any resource initializes, from exactly one environment variable per field: the bound name, otherwise `TELO_NEED_` + the need path's segments and the field in upper snake case joined by `__` (`Orders.databaseAccess` field `url` → `TELO_NEED_ORDERS__DATABASE_ACCESS__URL`; `HTTPServer` → `HTTP_SERVER`). A supply at an import wins over the environment. Values are decoded against the field's schema as a root variable's are, a failure joining the application's `ERR_MANIFEST_VALIDATION_FAILED` without printing a sensitive value; some variables of a need set and a required one not is `ERR_NEED_PARTIALLY_SUPPLIED`; a required need with none set is `ERR_NEED_UNMET`, now naming every variable to set; an optional one is `null`. Those names are hidden by exact name from `process.env` and `ctx.env`. `telo check` reports `NEED_ENV_NAME_COLLISION` (two need fields reading one name, or one a `variables:` / `secrets:` / `ports:` entry binds; `ERR_NEED_ENV_NAME_COLLISION` at load), `LIBRARY_ENV_KEY_REJECTED` for a library need's `env:` (`ERR_LIBRARY_ENV_KEY_REJECTED`), and `NEED_FIELD_UNDECLARED` / `NEED_SLOT_MISMATCH` for an `env:` map. `telo needs report <manifest>` prints, with nothing booted, every need read from the environment with its fields' variables; `-o json` writes a versioned document (`reportVersion: 1`, `needs[]` of `path`, `declaredBy`, `type { module, name }`, `parameters`, `optional`, `fields { env, envSource, required, sensitive }`).

The analyzer's need table now lists those needs as `environment` (replacing `unmet`; a need's supply form `unsupplied` is now `environment`), each with its fields' environment names, and exports `needGraphScopeOf`, `derivedNeedEnvName`, `envNameSegment` and `NEED_ENV_PREFIX`.
