## 0.11.0 - 2026-08-11
### Added
* Shell hosts log the command they run at debug and a non-zero exit at info. A non-zero exit RESOLVES — the caller receives exitCode and is free to ignore it — so a command that failed was indistinguishable from one that succeeded unless something read the field. Every other failure mode (spawn error, timeout, cancellation, signal) already rejects and reaches the caller.
